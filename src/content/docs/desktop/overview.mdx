The UFLinux desktop is a Wayland session assembled from a small number of components,
each chosen or written for a specific job. It has no GNOME or KDE dependencies.

## The stack

| Layer | Component |
| --- | --- |
| Compositor | [labwc](https://labwc.github.io/) |
| Panel / taskbar | `uflinux-desktop`, a resident GTK4 process written for UFLinux |
| Start menu | the same `uflinux-desktop` process |
| Settings UI | `uflinux-settings`, plain GTK4 |
| Session service | `uflinux-settingsd`, headless GLib/GIO |
| Privileged helper | `uflinux-settings-system`, root D-Bus + polkit |
| Greeter | ReGreet with the adw-gtk3 dark theme |
| Terminal | Ptyxis |
| File manager | UFLinux Files (`uflinux-files`, from the apps repository) |
| Notifications | Mako |
| Audio | PipeWire and WirePlumber, with `pipewire-pulse` |
| Networking | ConnMan with iwd |
| Power | TLP, plus a BusyBox `acpid` power-button hook |
| Time sync | ConnMan's SNTP client |

Settings and the desktop shell are Rust workspaces using plain GTK4 and the user's GTK
theme. Neither depends on libadwaita, GNOME Settings, or the GNOME settings daemon. The
Start menu is compiled into the `uflinux-desktop` binary, so the taskbar and the menu are
one process.

## Session start

OpenRC starts independent services in parallel for both live and installed systems.
`uflinux-defaults` sets `rc_parallel="YES"` in `/etc/rc.conf.d/uflinux.conf`; service
dependencies still determine ordering. Set `rc_parallel="NO"` in that file when
diagnosing a boot problem — the change takes effect on the next boot and survives
upgrades.

ReGreet starts the UFLinux session directly. There is no session selector. The unified
desktop is the default session: `uflinux-autostart` starts `uflinux-desktop --supervise`,
which keeps the resident shell running. The Start menu starts hidden with its widgets,
layout and application catalog already prepared, so opening it is fast.

## Renderer selection

The session wrapper probes hardware Vulkan, then hardware OpenGL, then pixman. It skips
Vulkan on Sandy Bridge, Ivy Bridge and Bay Trail Intel graphics, where Vulkan support is
incomplete, and it skips software Vulkan entirely. Explicit renderer overrides are
respected, and startup fallback attempts are limited.

A normal logout — or a crash after the desktop has started — does **not** restart the
session with a different renderer. On software rendering, GTK uses Cairo unless you
override it, and the quick-settings cards drop their blurred shadow to reduce
software-rendering allocations.

## Installed applications

Every architecture ships:

- **Firefox** with uBlock Origin
- **Ptyxis** terminal, opened with `Super` + `Enter`
- **Loupe** image viewer and **htop**
- **Celluloid** media player
- **Transmission** BitTorrent client
- **Mako** notifications
- **GNOME Disks** and **File Roller** for images and archives
- **gpu-screen-recorder** as the screenshot and screen-recording backend
- **BlueZ** for Bluetooth and ConnMan's VPN daemon for WireGuard tunnels

**UFLinux Files** (`uflinux-files`) comes from the apps repository on every supported
architecture. **Remote Desktop** (RDP) ships
in the image too, but **disabled by default**, so nothing listens on any port until you
turn it on — see [Remote Desktop](./remote-desktop.md).

## Memory

The installed desktop is built and accepted against a reference target of **512 MiB of
RAM, one display, and no swap**. The live image is a different story: it unpacks the
desktop and the full Papirus-Dark icon theme into a tmpfs root whose default capacity is 75%
of RAM, so live sessions need at least 4 GiB.

Background components are budgeted at ≤16 MiB PSS, the full Settings UI at ≤80 MiB, and
the flyout at ≤64 MiB. See [Validation record](../developer/validation.md) for measured
numbers.

## Taskbar layout

The taskbar carries the Start button, pinned favourites and running-window groups, the
tray, and separate **Network**, **Sound** and **Power** buttons with symbolic icons that
track connection state, output volume and battery. Desktop machines show a bolt instead
of a battery. Buttons can be pinned, reordered by dragging, and previewed on hover; the
clock opens a calendar with a notification centre. StatusNotifier icons from background
apps sit behind a single chevron so they cannot push the clock off a narrow panel.

Details in [Start menu](./start-menu.md) and [UFLinux Settings](./settings.md).
