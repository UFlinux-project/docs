The Start menu runs in the resident GTK4 `uflinux-desktop` process — the same process that
draws the taskbar. Login starts it hidden with its default widgets, layout and
application catalog already prepared, and it keeps them between openings — so the menu
appears immediately, and GTK and the compositor draw buffers only when the window is
mapped.

## Opening it

Click the leaf on the taskbar, or release either `Super` key. `Super` + `R` and
`Super` + `Space` also toggle it. It uses Papirus-Dark icons and your selected GTK theme.

The Start menu and the Network, Sound and Power menus replace each other, while a full
Settings window can stay open alongside them.

## Left column

Shortcuts to Files, Terminal, Settings, and your default web browser when one is
installed. **All Applications** opens the alphabetical catalog.

Typing in **Search** shows indexed applications first, then matching file and folder names
from the file manager's configured search roots. Local application matches supplement the
index when localized names or keywords differ, and stay available if the search service is
absent. Applications launch through GIO desktop-entry handling; files and folders open in
their default applications. Every result row shows its icon with the program or file name
vertically centered against it, so the text stays level with the icon instead of sitting at
the top of the row.

## Right column

Your account name, Home, your configured XDG folders, Settings and Terminal. Folders that
are unavailable show an explanation. `xdg-user-dirs` creates the standard folders at login
and respects existing configuration.

Favorites are fixed. There is no tracking of recent files or recent applications.

## Taskbar buttons, pinning and previews

Beside the Start button, application buttons come from the pinned favourites in
`$XDG_CONFIG_HOME/uflinux/taskbar.json` plus the running-window groups. Right click opens
a menu listing the group's windows with a close button each and, for applications, entries
to launch another window, pin or unpin the button, and close all windows. Pinned buttons
can be rearranged by dragging one onto another; the new order is written back to the same
file, and an unreadable file falls back to the defaults rather than blocking the panel.

Resting the pointer on a running app opens thumbnail cards with activation and close
controls. **Settings → Appearance → Window previews** governs both these images and
labwc's native Alt+Tab thumbnail grid, and it defaults to enabled; with previews off,
hover cards keep their titles and Alt+Tab uses the classic list. Capture only runs while
cards are visible: up to two frames per second per window and four per second in total,
images at most 320×180, a cache of at most 64 images under 16 MiB expiring after 30
seconds. Unsupported capture and oversized sources fall back to icons and titles.

The clock opens a popover with a month-navigable calendar and a notification centre that
reads Mako's list while the popover is open and dismisses notifications individually or
together. Mako itself is styled as dark rounded cards grouped by summary, anchored
bottom-right above the taskbar.

## Power actions

Log out, Restart and Shut down ask for confirmation with **Cancel** selected by default.
Suspend is immediate. Actions elogind reports as unavailable are disabled, and
authorization errors appear inside the menu. The physical power-button policy lives in
Settings, not here.

## Keyboard behaviour

Search takes focus when the menu opens. Arrow keys move through the results and `Enter`
opens the selection. `Escape` works in stages: it cancels a confirmation, then clears
the search, then returns from All Applications, and finally closes the menu. Clicks
outside close it immediately. Closing resets search, selection and confirmations, but does
not destroy the catalog.

## Multiple monitors

```sh
uflinux-desktop --start-menu --output DP-1
uflinux-desktop --panel network --output HDMI-1
```

With no `--output`, labwc chooses the monitor that received the keyboard activation;
taskbar buttons always supply their originating monitor. The transparent layer captures
outside clicks and the Start button while leaving other taskbar controls usable. Removing
an output closes the menu, and the card adapts to smaller outputs and compositor scaling.

Taskbar menus can be opened directly:

```sh
uflinux-desktop --panel network|sound|power --output NAME
```

## Controlling the resident process

| Command | Effect |
| --- | --- |
| `uflinux-desktop --daemon` | Start or ensure the hidden resident process |
| `uflinux-desktop --hide` | Dismiss the menu |
| `uflinux-desktop --status` | Report readiness and visibility |
| `uflinux-desktop --quit` | End the process explicitly |

Desktop-file changes refresh the catalog while the menu is hidden. Being resident is part
of the desktop's background memory cost.

## Tray icons

StatusNotifier icons sit behind a single chevron at the right end of the taskbar, like the
hidden-icons flyout on Windows, so background apps cannot push the clock off a narrow
panel. The chevron is hidden while nothing is registered, and its tooltip and accessible
name report how many icons are behind it.

The flyout is a grid of square icons above the panel, four to eight columns wide depending
on the output, and scrolls when it grows taller than the flyout allows. Left click
activates an item, or opens its menu when it declares `ItemIsMenu`. Right click always
opens the menu. Scrolling over an icon sends its `Scroll` event. Only one tray menu is
open at a time, and the flyout stays open while one of its menus is up.

## Relationship to Settings

The desktop connects to the Settings state service and provides the session polkit agent.
Settings shortcuts start `uflinux-settings` as a separate process.
