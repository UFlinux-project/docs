UFLinux ships a dark desktop assembled from upstream themes rather than bespoke ones. The
icon theme and default wallpaper follow those selected by the
[original UFLinux configuration](https://github.com/UFlinux-project/main): Papirus and
GNOME's *Dark Ivy*.

| Aspect | Default | Source |
| --- | --- | --- |
| Icons | Papirus-Dark | Alpine's signed `papirus-icon-theme` |
| Pointer | `simp1e-cursors-adw-dark` | `simp1e-cursors`, built from pinned upstream source |
| GTK3 and GTK4 | `adw-gtk3-dark` | Alpine's signed `adw-gtk3` |
| Window decorations | `labAdwaita-dark` | labwc |
| Wallpaper | Dark Ivy | GNOME 3.38 artwork |
| Fallback icons | Adwaita | Alpine |

GTK3, GTK4, labwc, ReGreet and Mako all select Papirus-Dark; the desktop shell takes its
application icons from the configured GTK icon theme.

The pointer uses the Adwaita dark scheme of the `simp1e-cursors` theme, built from the
pinned upstream source in `aports/simp1e-cursors`. Only the base theme and that variant are
generated, so the recipe is a trimmed copy of Alpine's `testing/simp1e-cursors`: the package
is not in the pinned release's main and community repositories, and Alpine's 49 scheme
subpackages would be wasted space. The variant ships as its own `simp1e-cursors-adw-dark`
package, which depends on the base `simp1e-cursors` package so that selecting the variant
also pulls the scheme it extends. GTK and GSettings pick it up from the drop-ins below,
ReGreet from its `cursor_theme_name` option, and labwc — which has no cursor option in
`rc.xml` — from `XCURSOR_THEME` in `/etc/xdg/labwc/environment`.

No global `GTK_THEME` override is set, so personal themes and accessibility preferences
can take precedence.

## Changing the theme

Use **Settings → Appearance**. The wallpaper chooser starts in the bundled collection, and
**Restore default wallpaper** selects Dark Ivy again.

Personal preferences always win over the packaged defaults:

- GTK3 and GTK4 read XDG `settings.ini` files and matching GSettings schema defaults.
  GTK3 on Wayland reads the desktop schemas when installed, which take precedence over
  `settings.ini`; the packaged schema override is what keeps the theme, icons, cursor and
  font consistent and selects the dark colour scheme. Your own GSettings preferences for
  GTK3 and your personal `settings.ini` for GTK4 still take precedence over it.
- labwc decorations and menus come from `labAdwaita-dark`. A session helper reads the
  selected GTK3 theme's named header colours once at startup and applies them to labwc, so
  **theme changes take effect at the next login**.

To take manual control of labwc decorations, edit the first line of
`~/.config/labwc/themerc-override` (or your own `rc.xml`) — a personal file stays in
control. Themes without simple named header colours, and GTK4 apps with their own theme
overrides, may still look different.

## Wallpapers

Six original GNOME 3.38 wallpapers are installed unmodified in `/usr/share/backgrounds/uflinux/`:
Dark Ivy, Cold Warm, Endless Shapes, Road, and the two Symbolics images. Dark Ivy is the
login default. No GNOME desktop or settings daemon is involved, and no wallpaper is
fetched at login.

Wallpaper settings accept local files up to 32 MiB and 16 megapixels, with fit, colour and
per-output preferences. The resident desktop shell draws them itself on background
surfaces — there is no separate wallpaper daemon.

## The leaf logo

The leaf is the simplified logo copied unchanged from the
[UFLinux website](https://uflinux.org/assets/logo.svg) on 17 November 2026. It appears on the
taskbar Start button and as the [startup animation](./bootsplash.md) fallback. The imported
SVG is checked against the exact upstream bytes recorded in the build's artwork lock. Settings
uses the icon theme's `preferences-system` gear icon instead of branded artwork, so its icon
follows your icon theme.
