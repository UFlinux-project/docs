These are the packaged defaults. The compositor configuration lives in `/etc/xdg`, and
`~/.config/labwc/` overrides it — see [Appearance and themes](../desktop/appearance.md).

## Session

| Keys | Action |
| --- | --- |
| `Super` | Open the Start menu |
| `Super` (release either key) | Toggle the Start menu |
| `Super` + `R` | Toggle the Start menu |
| `Super` + `Space` | Application launcher |
| `Super` + `Enter` | Terminal (Foot) |
| `Super` + `E` | Files (Nemo) |
| `Super` + `D` | Show the desktop |
| `Super` + `I` | UFLinux Settings |

Releasing either `Super` key opens the Start menu, so a lone `Super` tap is a launcher
gesture. `Super` + `Space` opens the launcher inside the Start menu rather than a separate
search utility.

## Screenshots and recording

| Keys | Action |
| --- | --- |
| `Print Screen` | Screenshot and recording overlay |
| `Shift` + `Print Screen` | Start a recording immediately |
| `Ctrl` + `Print Screen` | Start a recording immediately |

The overlay is `uflinux-screencapture`, launched on demand. Screenshots are saved as WebP
in your Pictures folder and copied to the clipboard. Recording goes through a patched
`gpu-screen-recorder`; hardware encoding needs a VA-API driver, and the desktop ships the
Mesa gallium driver plus both Intel VA-API drivers so recording works out of the box on AMD
and Intel GPUs.

Format, folder, clipboard, flash, cursor capture, delay, recording target, quality preset,
audio source and frame rate are all configured in
[Settings → Screen capture](../desktop/settings.md#screen-capture).

## Audio and brightness

Volume and brightness hotkeys use the same settings backend as the panel menus and the
Settings application, so a hotkey change and a slider change update the same state. From a
terminal, the same backend is reachable with:

```sh
uflinux-settingsctl volume -5
uflinux-settingsctl brightness 5
uflinux-settingsctl mute
```

## Start menu navigation

Search takes focus when the menu opens. Arrow keys move through applications and `Enter`
launches the selection. `Escape` works in stages: it cancels a confirmation, then clears the
search, then returns from All Applications, and finally closes the menu.

## Live session credentials

On the live image, the desktop logs in automatically as `live`. On a serial console, use
**live / live**. The account has passwordless local `doas`, root is locked, and SSH is
disabled.
